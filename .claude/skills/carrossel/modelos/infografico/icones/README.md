# Kit de ícones — modelo infografico

Ícones de linha da coleção **Tabler Icons** (licença MIT), variante *outline*, guardados como vieram (`stroke="currentColor"`, `stroke-width="2"`, viewBox 24). O build troca pra **traço branco, espessura 1.2** — no tamanho de uso (90–150 px) isso dá o traço grosso dos posts de referência.

**Regra de entrada:** só ícone de **traço fechado**, que não pareça cortado no fundo escuro (reprovado em 26/09: aperto de mão com traço aberto; os de pessoa com corpo em arco aberto ficaram de fora pelo mesmo motivo). Ícone novo: baixar de `https://cdn.jsdelivr.net/npm/@tabler/icons@3/icons/outline/<nome>.svg`, conferir no fundo escuro em 120 px, salvar aqui e registrar abaixo. Nunca ícone gerado por IA.
